# Automated Monetization

코딩 초보가 Claude와 Claude Code로 콘텐츠 수익화(블로그, 인스타 카드뉴스)를 단계별로 만들어 가는 기록입니다.

## 현재 방향 (2026-11-10 기준)

- **메인 채널:** 해외송금·가상자산 실무자 관점의 사기 예방 블로그 + 인스타 카드뉴스
- **가제:** 돈길 노트 (부제: 해외송금·코인 사기 실무 노트)
- **포지션:** 법무법인·경찰 출신 블로그가 "당한 뒤"를 다룬다면, 이 채널은 "보내기 직전(송금·코인 전환 순간)"에 거르는 법을 다룬다
- 여행 블로그 방향은 2026-11-09에 보류 (여행을 자주 가지 않아 소재가 부족)

## 지킬 원칙

- 회사 이름, 사내 이름, 내부 사례·탐지 기준·고객 정보는 어떤 자료에도 넣지 않는다
- 사기 예방 콘텐츠는 경찰청·금감원·언론 보도 등 공개 자료만 근거로 쓴다
- 특정 코인·거래소·송금업체를 추천하지 않는다 (투자 권유, 이해충돌 위험)
- 이미지는 직접 찍은 사진이나 무료 라이선스만 쓴다
- 제휴 링크·협찬이 들어가면 "광고" 표시
