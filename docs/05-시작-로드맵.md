# 시작 로드맵: 무엇부터 할까

2026-11-15 작성. "자동화 수익화, 뭐부터 해야 할지 1도 모르겠다"는 질문에 대한 답입니다.

## 먼저 알아둘 원칙

- **자동화는 맨 마지막입니다.** 손으로 3번 해본 일만 자동화합니다. 글이 하나도 없으면 자동화할 대상도 없어요.
- **수익 = 쌓인 글 × 찾아오는 사람.** 자동화는 글 쓰는 시간을 줄여주는 도구일 뿐, 수익을 만들어주지는 않아요.
- **첫 3개월은 수익이 거의 없습니다.** 애드포스트도 개설 90일이 지나야 신청할 수 있어요.

## 오늘 할 일 (10분)

- [ ] 네이버 블로그 → 관리 → 블로그 정보
- [ ] 블로그 이름: 돈길 노트
- [ ] 소개: 해외송금과 가상자산 업계에서 일하는 실무자가, 돈이 빠져나가기 전에 거르는 법을 공개 자료로 정리합니다.
- [ ] 카테고리 4개: 해외송금 사기 / 코인 사기 / 미리 막기·당했을 때 / 제도 쉽게 읽기

## 1주차: 첫 글 1개 (손으로)

1. 주제: "비대면 계좌개설 안심차단 신청 방법, 은행 앱으로 5분이면 끝"
2. 내 은행 앱에서 직접 신청해 보면서 화면을 캡처 (이름·계좌번호는 가리기)
3. Claude에게 "이 캡처 순서대로 블로그 초안 써줘"라고 부탁
4. 초안을 내 말투로 고치고, 내가 해본 느낌 한두 줄 넣기
5. 발행

## 2주차: 글 2개 더 + 인스타 시작

1. 블로그 글 2개 더 (`02-사기예방-블로그-방향.md`의 첫 글 제목 후보에서 고르기)
2. 인스타 계정 만들기 (`03-인스타-카드뉴스-계정-시작-가이드.md`의 '집에서 할 일')
3. 1주차 블로그 글을 카드뉴스 8장으로 바꿔서 첫 게시물 올리기

## 3주차: 반복되는 일 찾기

글 3개를 쓰면서 매번 똑같이 한 일을 적어봅니다. 예를 들면 이런 것들이에요.

- 경찰청·금감원 공개 자료 찾기
- 초안 뼈대 잡기 (요약 → 단계 → 주의 → 마무리)
- 블로그 글에서 카드뉴스 문구 8장 뽑기

## 4주차: 첫 자동화 1개

Claude Code로 "주제 한 줄을 넣으면 블로그 초안 + 카드뉴스 문구 8장이 나오는 도구"를 만듭니다. 이미 만들어 둔 글 생성 코드를 고쳐서 쓰면 돼요.

## 2~3개월차

- 일주일에 블로그 2~3개, 카드뉴스 2~3개 꾸준히
- 통계에서 반응 좋은 글을 찾고 비슷한 글 더 쓰기
- 개설 90일이 지나면 애드포스트 신청
