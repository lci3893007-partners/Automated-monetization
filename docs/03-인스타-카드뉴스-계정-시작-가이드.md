## 잘 되는 카드뉴스 공식 (가설)

1. 장수는 8~10장: 저장률과 완독률이 함께 높은 구간 ([1point](https://1point.kr/blog/insights/high-save-cardnews-formula/), [PostEverywhere](https://posteverywhere.ai/blog/instagram-carousel-best-practices))
2. 표지가 성과의 대부분을 결정하고, 2장도 두 번째 후킹으로 만든다
3. 제목은 답을 숨긴다: '명소 39가지'보다 '가야 하는 이유' ([고구마팜](https://gogumafarm.kr/?p=27932))
4. 번호를 매기고 같은 디자인을 반복한다 ([AMPM](https://inside.ampm.co.kr/insight/10685))
5. 시의성이 내용보다 중요할 때가 많다: 계절, 월별 이벤트, 최근 이슈 ([링커리어 운영자 경험담](https://community.linkareer.com/jayuu/6146585))
6. 세로 비율(4:5 또는 3:4), 영상 슬라이드 1장 섞기

## 다음 단계: 카드뉴스 생성기

분석이 끝나면 Claude Code로 '주제 한 줄 → 카드 8~10장 이미지'를 만드는 프로그램을 만듭니다.

1. 분석 기준표에서 가장 반응 좋은 디자인 1~2개를 내 템플릿으로 정하기 (색·폰트·배치)
2. Claude Code에게 템플릿을 말로 설명하고 표지 1장만 만들어보기
3. 본문 장과 마지막 장(저장·팔로우 유도) 추가
4. 주제 한 줄을 넣으면 문구 작성부터 이미지 저장까지 한 번에 되게 묶기
5. 블로그 글을 넣으면 카드뉴스로 바꿔주는 기능 추가

업로드는 처음에 직접 손으로 합니다. 자동 게시는 계정이 자리 잡은 뒤 인스타 공식 API로 다시 검토합니다.

## 주의사항

- 회사 기기·회사 계정과 완전히 분리
- 남의 카드뉴스 이미지·문구를 그대로 가져다 쓰지 않기
- 뉴스 기사 본문·보도사진 사용 금지: 내 말로 요약 + 출처 표기 + 직접 만든 그래픽
- 자동 팔로우·좋아요·댓글 프로그램 금지
- 제휴 링크나 협찬이 들어가면 '광고' 표시
- 사기예방 콘텐츠는 공개 자료만, 회사 내부 사례·룰·고객 정보는 절대 사용하지 않기
