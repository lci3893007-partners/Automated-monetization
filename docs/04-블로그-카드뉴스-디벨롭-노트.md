## 노베이스 블로그 시작 순서

블로그는 예쁘게 꾸미는 것보다 글을 먼저 쌓는 게 순서입니다. 잘되는 블로거들도 처음에는 무료 기본 스킨을 그대로 쓰고 프로필·카테고리만 정했다고 말해요 ([월부](https://weolbu.com/community/3241632), [애드센스팜](https://adsensefarm.kr/%eb%84%a4%ec%9d%b4%eb%b2%84-%ea%b2%bd%ec%a0%9c-%eb%b8%94%eb%a1%9c%ea%b7%b8-1%ec%9c%84%ea%b0%80-%eb%a7%90%ed%95%98%eb%8a%94-%eb%b8%94%eb%a1%9c%ea%b7%b8%eb%a1%9c-%eb%8f%88-%eb%aa%bb-%eb%b2%84%eb%8a%94/)).

1. **주제 하나 정하기:** 한 분야를 꾸준히 써야 검색에 잘 떠요
2. **블로그 만들기:** 네이버 로그인 → 블로그 → 내 블로그 열기
3. **이름·소개·프로필 사진 정하기:** 관리 → 블로그 정보. 누가 쓰는 블로그인지 보이게
4. **카테고리 3~5개 만들기:** 한 번 정하면 그대로
5. **스킨은 기본 그대로:** 예쁘게 꾸미기는 나중에. 지금은 글씨체(서체)만 정하기
6. **첫 글 쓰기:** 긴 제목 + 내가 만든 자료
7. **글 10개 썼나?** 아니면 6번으로 돌아가 한 편 더 쓰기
8. **반응 좋은 글 찾기:** 통계에서 많이 본 글 확인 → 비슷한 글 더 쓰기
9. **이제 꾸미기·수익 알아보기:** 스킨 꾸미기, 애드포스트(개설 90일 후)·제휴 링크 신청

'10개'는 연습 기준으로 제안한 숫자이고, 네이버가 정한 숫자는 아닙니다. 메뉴 위치는 화면이 바뀌었을 수 있어 직접 한 번 더 확인합니다.

## 네이버가 좋은 글로 보는 기준

네이버는 '누가 썼는가'(C-Rank)와 '무엇을 썼는가'(D.I.A.)를 함께 봅니다. 새 블로그도 내용이 충실하면 상위에 뜰 수 있고, 오래된 블로그도 내용이 부실하면 밀립니다 ([네이버 공식 설명 정리](https://brunch.co.kr/@chatsapiens/9)).

| 기준 | 보는 것 | 할 일 |
| --- | --- | --- |
| C-Rank (누가) | 한 주제에 얼마나 꾸준히 쓰는지, 댓글·공유 같은 반응 | 한 주제만 꾸준히, 다른 주제 섞지 않기 ([inblog](https://inblog.ai/ko/glossary/c-rank)) |
| D.I.A. (무엇) | 주제 적합도, 작성자의 경험, 정보 충실성, 검색 의도 부합, 독창성, 최신성, 어뷰징 여부 | 직접 경험·실제 자료 넣기, 남의 글 베끼지 않기 |

두 기준 모두 '내가 직접 겪은 경험'에 가장 크게 반응합니다. Claude Code로 글을 만들더라도 내 경험과 관점은 직접 넣어야 하는 이유입니다.

## 블로그 제목 패턴

초보 블로그는 '짧고 넓은 제목'이 아니라 '길고 구체적인 제목'으로 가야 검색에 뜹니다. 상위 글들은 제목이 거의 같은 부품으로 조립돼 있어요 ([트립스토어](https://www.tripstore.kr/blog/tags/%E1%84%8B%E1%85%A9%E1%84%89%E1%85%A1%E1%84%8F%E1%85%A1%E1%84%8B%E1%85%A7%E1%84%92%E1%85%A2%E1%86%BC), [여기어때](https://www.yeogi.com/content/tripholic-ob-jp-osaka-3-nights-itinerary)).

**제목 조립 공식: 무엇(상황) + 누구 + 어떤 조건 + 숫자 + 무엇을 주는지**

| 부품 | 상위 글에서 쓰는 말 (여행 예시) | 왜 효과가 있나 |
| --- | --- | --- |
| 어디 + 얼마나 | 오사카 3박 4일, 후쿠오카 2박 3일 | 사람들이 검색창에 치는 말 그대로 |
| 누구와 | 부모님과, 아이와, 커플, N회차, 2030 | '내 얘기다' 하고 누름 |
| 어떤 상황 | 비 와도 됨, 체력 부담 없는, 걷기 적은 | 대표 키워드보다 경쟁이 훨씬 적음 |
| 숫자 | 예산 금액, BEST 5, 교통비 | 클릭 전에 얻을 것이 보임 |
| 무엇을 주는지 | 총정리, 동선, 꿀팁, 완벽 가이드 | 저장하고 다시 볼 글이라는 신호 |

**초보가 피해야 할 제목** ([N잡냥이](https://maily.so/tiyou/posts/vpzl8mv2rk9))
- '일본 여행'처럼 짧고 넓은 제목: 문서 수가 수백만 건이라 새 블로그는 묻힘
- 브랜드명만 있는 제목: 공식 사이트·광고·뉴스가 위를 차지
- '오늘의 일상' 같은 일기형 제목
- 연예·사건 속보: 방문은 늘어도 블로그 주제가 흐려짐

고치기 예시: '오사카 여행' → '오사카 3박4일 부모님과 걷기 적은 코스 (실제 동선·교통비 포함)'

한 번의 경험으로도 '경비 정리', '동선', '대처법' 글을 따로 쓸 수 있습니다. 네이버 노출은 검색과 홈피드(앱 추천) 두 가지이고, 초보는 검색형 정보 글부터 시작하는 것이 정석입니다 ([월부 칼럼](https://weolbu.com/community/3419681)).

## 블로그 본문 어순

상위 글은 '요약 먼저, 경험은 단계별로, 팁과 주의는 마지막'의 순서를 따릅니다. 이 순서를 Claude Code 글 생성기의 뼈대로 쓰면 됩니다.

1. **첫 3줄 요약:** 첫 문장에 핵심 답(동선과 총예산 같은)을 한 줄로 먼저 답하고, 이어서 이런 사람에게 추천·가기 좋은 시기
2. **짧은 인사 + 기본 정보:** 언제, 누구와, 며칠
3. **전체 일정표:** 단계 / 장소 / 방법 / 비용을 표로
4. **단계별 본문:** 장소 → 직접 찍은 사진 → 솔직한 느낌 → 한 줄 팁
5. **고민했던 선택지 비교:** A와 B 중 왜 이걸 골랐는지
6. **자주 묻는 질문:** 검색하는 사람의 궁금증을 질문 그대로 소제목으로 ([tilnote](https://tilnote.io/pages/69b740b0a94db6d7036d5eea))
7. **마무리 + 변동 안내:** 바뀔 수 있는 정보는 방문 전 확인
8. **이런 사람에게 추천:** 마지막에 한 번 더 대상 정리

'광고 포함' 표시는 글 맨 위에 둡니다. '내가 겪은 것 + 내 느낌'이 AI 양산글과 구별되는 핵심이라, 자동화해도 이 부분은 직접 채워야 합니다.

## 카드뉴스 장별 어순

10장 기준으로, 가장 강한 내용은 8~9장에 둡니다. 참여도가 3장 이후 떨어졌다가 8장부터 다시 오른다는 데이터가 있고 ([PostEverywhere](https://posteverywhere.ai/blog/instagram-carousel-best-practices)), 안 넘긴 사람에게 2장을 다시 보여주는 경우가 있어 2장도 두 번째 표지처럼 만듭니다. 구성은 '표지 → 문제 → 근거 → 사례 → 실행 → 요약' 흐름을 따릅니다 ([캐럿](https://carat.im/de/prompt-gallery/card-news-examples)).

| 장 | 역할 | 여행 예시 (12월 삿포로) | 사기예방 예시 (해외 송금 부탁) |
| --- | --- | --- | --- |
| 1 | 표지: 답을 숨긴 한 줄 | 12월에 삿포로 가야 하는 이유 | "돈 좀 보내줘" 오면 먼저 할 일 |
| 2 | 두 번째 후킹: 공감·문제 | 다들 2월 눈축제만 알지만 | 해외 간 지인 이름으로 온 메시지 |
| 3 | 왜 지금인가 (근거 1) | 12월이 좋은 이유 하나 | 실제로 많이 쓰이는 수법 |
| 4 | 근거 2 | 숫자 하나 (확인된 것만) | 공개된 피해 통계 하나 |
| 5~7 | 사례·단계, 번호 매기기 | 추천 장소 1·2·3 | 의심 신호 1·2·3 |
| 8~9 | 가장 쓸모 있는 내용 | 동선·꿀팁 정리 | 확인 순서와 신고 번호 |
| 10 | 요약 + 행동 유도 | 저장해두고 여행 전 꺼내보기 | 부모님께 공유하기 |

표지 아래 보조 문구는 표지가 던진 궁금증에서 벗어나지 않게 이어 씁니다 ([AMPM](https://inside.ampm.co.kr/insight/87)). 숫자나 일정은 항상 공식 자료로 확인한 뒤 넣습니다.

## 카드뉴스 만들기·게시 체크리스트

저장되는 카드뉴스는 디자인보다 흐름이 결정합니다. 1~3장은 멈추게, 4~6장은 저장하게, 7~8장은 행동하게 만드는 구조예요 ([원포인트](https://1point.kr/blog/insights/high-save-cardnews-formula/)).

**만들 때**
- [ ] 한 장에 포인트 하나만, 다음 장이 궁금하게 살짝 덜 끝내기
- [ ] 1장 후킹은 네 가지 중 하나: 문제 제기형(질문), 호기심형(몰랐던 사실), 대담한 주장형(통념을 숫자로 뒤집기), 공감형(일상 속 구체적 순간)
- [ ] 1장에 결론을 다 보여주지 않기
- [ ] 2장·3장은 단독으로 봐도 궁금하게
- [ ] 4~6장은 체크리스트·단계·비교표처럼 따라 할 수 있는 형태로
- [ ] 7장에서 부드럽게 저장 권하기, 8장에서 행동 하나만 (공유라면 '부모님께 보내드리기'처럼 대상을 콕 집기)

**올릴 때**
- [ ] 배경음악 추가: 릴스 탭에도 노출될 수 있음
- [ ] 짧은 영상 슬라이드 1~2장 섞기
- [ ] 캡션 첫 줄에 검색할 만한 핵심 키워드 ([AJ Marketing](https://www.ajmarketing.io/ko/post/%EC%9D%B8%EC%8A%A4%ED%83%80%EA%B7%B8%EB%9E%A8-%ED%8C%94%EB%A1%9C%EC%9B%8C%EB%A5%BC-%EB%8A%98%EB%A6%AC%EB%8A%94-7%EA%B0%80%EC%A7%80-%EB%B0%A9%EB%B2%95))
- [ ] 올리고 1시간 안에 스토리로 다시 공유
- [ ] 몰아서 올리지 말고 일주일에 3개씩 꾸준히

좋아요보다 저장·공유 수가 더 중요하게 평가된다는 것이 업계의 공통 의견이라, 성과도 저장 수로 판단합니다 ([아이보스](https://www.i-boss.co.kr/ab-6141-67017)).

## 애드포스트 시작 전 알아둘 것

- 신청 시점: 개설 후 90일이 지나야 신청 가능하고, 양질의 글이 있어야 심사를 통과한다고 알려져 있음 ([옐로우IT](https://yellowit.co.kr/%EA%B2%80%EC%83%89%EC%97%94%EC%A7%84-%EC%B5%9C%EC%A0%81%ED%99%94/%EB%84%A4%EC%9D%B4%EB%B2%84-%EC%95%A0%EB%93%9C%ED%8F%AC%EC%8A%A4%ED%8A%B8-%EA%B0%80%EC%9E%85-%EB%B0%8F-%EA%B4%91%EA%B3%A0%EC%8B%A0%EC%B2%AD-%EC%9E%90%EA%B2%A9/)). 오래된 글 기준이라 신청 전에 애드포스트 공지로 한 번 더 확인
- 지급: 계좌 인증과 자동지급을 켜야 하고, 기본 최소 지급액은 5만 원
- 금지: 내 광고 직접 클릭, 지인에게 클릭 부탁, 자동 클릭 프로그램, 글에 클릭 유도 문구. 적발되면 이미 지급된 수익도 회수될 수 있음

회사 밖 수익이 생기면 5월 종합소득세 신고 대상이 될 수 있습니다 ([잡가이버](https://jab-guyver.co.kr/m/1845)).
