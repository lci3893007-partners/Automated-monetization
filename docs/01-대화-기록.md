## 2026-11-06 (금)

### 1. 수익화 방법 탐색
- 질문: 코딩을 전혀 모르는 컴플라이언스 실무자가 Claude·Claude Code로 A부터 Z까지 자동화해서 수익화할 방법
- Claude 답변 요지
  - 완전 자동 양산형(블로그·쇼츠)은 플랫폼 저품질·반복 콘텐츠 정책 때문에 오래가기 어렵고, "반자동 + 내 관점"이어야 살아남음
  - 진짜 강점은 해외송금·AML·보이스피싱 대응 실무 경험
  - 수익화 5가지(현실성 순): 전문 콘텐츠(블로그 → 전자책·강의), 블로그·쇼츠 반자동화, 업무 자동화 대행, 실무 도구 제작·판매, 사내 업무 자동화로 커리어 가치 상승
  - 추천 순서: 1~2개월 Claude Code 익히기 → 2~3개월 블로그 시작 → 4~6개월 일부 자동화·쇼츠 → 이후 전자책·대행

### 2. 쇼츠·블로그 구체화
- 내 계획: 블로그는 여행 양산형, 유튜브 쇼츠는 영화·영상을 가져와 자동 리뷰 (한국인용, 외국인용 계정)
- Claude 의견
  - 영화 클립 자동 리뷰 쇼츠는 저작권 형사 사건 사례가 이어지고 있고(2026년 8월 26개 채널 37억 원 송치 등), 유튜브의 반복·대량 생산 콘텐츠 정책(2025년 7월~)에도 걸려 도와주기 어려움
  - 대안: 블로그와 같은 주제의 쇼츠로 전환(직접 찍은 영상, 무료 라이선스 소스)
  - 여행 블로그는 가능. 수익은 애드포스트보다 호텔·투어 제휴, 이미지는 직접 찍은 것만, 가격·운영시간은 반드시 확인
  - 겸업: "연 1,500만 원 미만이면 괜찮다"는 법이나 규정에 있는 기준이 아님

### 3. 인스타 카드뉴스와 네이버 블로그 조회
- 카드뉴스는 Claude Code 입문 프로젝트로 추천. 기사 문장·보도사진은 그대로 쓰지 않기
- 네이버 블로그 읽기는 computer use보다 내장 브라우저나 Claude in Chrome이 적합. 자동화 단계에서는 네이버 검색 API
- 남의 블로그 캡처·사진을 내 글에 넣지 않기, 로그인 상태 자동 글쓰기는 계정 제한 위험

### 4. Claude Code 진행 상황
- 글 생성까지 만들었음. 사진을 더 찍어야 다음 단계 진행 가능
- 사진 찍을 때: GPS 켜두기, 세로·가로 둘 다, 5~10초 영상, 메뉴판·가격표·안내판 사진. 업로드 전에는 위치 정보 지우기
- 프로젝트 폴더: C:\Projects 근처에 저장됨 → `photos` 폴더를 만들어 사진 넣기

### 5. 카드뉴스 상위 패턴 분석
- 조회수는 계정 주인만 볼 수 있어 공개 지표(좋아요·댓글)와 업계 분석으로 대체
- 공식: 8~10장, 표지가 대부분 결정, 답을 숨기는 제목, 번호 매기기 + 반복 디자인, 시의성, 세로 4:5
- 결과물: [인스타 카드뉴스 계정 시작 가이드](https://claude.ai/artifact/HxtpCDCJR2YRyFJfLdE6Mw) → `docs/03` 참고

### 6. 블로그·카드뉴스 디벨롭
- 요청: 여러 블로그·카드뉴스를 보고 문구·어순을 학습, 노베이스 블로그 시작 순서도
- 결과물: [디벨롭 노트](https://claude.ai/artifact/TNE3s3xFFiUyq54h2TaUvt) → `docs/04` 참고 (제목 공식, 본문 어순, 표지 6유형, 장별 구성, C-Rank·D.I.A., 체크리스트, 애드포스트, 참고 링크)
- 카드뉴스 예시 4종 디자인 → `cardnews/` 참고. 첫 버전이 밋밋하다는 피드백으로 사진 꽉 찬 표지, 형광펜 강조, 폴라로이드, 손글씨 스타일로 다시 디자인
- 무료 사진 사이트는 작업 환경에서 막혀 있어 사진 자리는 임시 그라데이션. 내 사진을 넣거나 도메인을 허용하면 교체 가능

### 7. 방향 전환: 여행 → 직무 관련
- 정정: 여행은 자주 가지 않음. 직무와 관련해 일상생활에 도움이 되고 조회가 많을 주제
- Claude 제안: "내 돈·내 통장 지키는 생활금융 보안" 채널
  - 2025년 보이스피싱 피해액 1조 2,578억 원(최근 5년 최대), 1건당 평균 약 5,384만 원, 기관사칭형이 78.6%
  - 4가지 축: 유행 수법 해설 / 미리 막는 설정법 / 당했을 때 대처법 / 해외송금·해외결제 생활정보
  - 사진 부담이 적어 자동화와 더 잘 맞음

## 2026-11-21 (토)

### 12. 비개발자 게임 만들기
- 비개발자 출신이 게임을 만든 유튜브 영상을 보고, 나도 하려면 뭘 알아야 하는지 질문 (영상은 Claude가 열지 못해 내용 확인 못 함)
- 알아야 할 것: 문법보다 만들고 싶은 걸 말로 정확히 설명하는 능력, 작게 쪼개서 하나씩 확인, 에러 메시지 붙여넣기, Git으로 저장·되돌리기, 게임 루프·충돌 같은 기본 개념 몇 개
- 첫 게임은 브라우저에서 바로 돌아가는 웹 게임(HTML·JavaScript)이 가장 쉬움. 배포는 itch.io, 무료 그림·소리는 Kenney 같은 무료 라이선스
- 게임 자체로 돈 벌기는 어려움 → 블로그 주제와 연결한 "사기 문자 구별 게임"을 제안 (블로그·카드뉴스 유입용)

### 13. 아이디어: 일기 기반 아침 피드백
- 아이디어: 일기를 쓰고, 그 일기를 바탕으로 매일 아침 나에게 피드백을 받기
- 평가: 내 문제를 푸는 좋은 아이디어이고 이미 노션 하루일기를 쓰고 있어 바로 만들 수 있음. 다만 앱으로 팔기엔 AI 일기 앱 경쟁이 치열하고(Rosebud 등), 정신건강 쪽은 민감해서 '치료'로 포지셔닝하면 위험
- 순서: ① 나만 쓰는 버전(노션 일기 + 매일 아침 예약 작업) ② 2~4주 써보고 효과 확인 ③ 차별점(한국 직장인, 목표 실행 코치)이 보이면 노션 템플릿·가이드 판매나 블로그 콘텐츠로
- 확인: 나만 쓰는 버전(일기 → 아침 피드백)은 이미 쓰고 있고 만족 중
- 다음 단계 제안: 무엇이 좋았는지 구체적으로 적기(= 차별점·판매 문구) → 지인 3~5명이 스스로 세팅해 2주 써보기 → 반응 좋으면 노션 템플릿 + 설정 가이드로 판매. 다른 사람 일기를 내가 받아서 처리하는 구조는 개인정보 부담이 커서 피하기
- 질문: 앱 형태로 팔면 어떤가
- 답: 가능하지만 템플릿보다 훨씬 무거움. 남의 일기를 서버에 보관(개인정보처리방침, 건강 등 민감정보는 별도 동의), 사용자마다 매일 드는 AI 호출 비용, 로그인·결제·고객 응대, 앱스토어 심사와 수수료, Rosebud 등 경쟁. 순서: 템플릿으로 수요 확인 → 대기자 모집 페이지로 "돈 낼 사람" 확인 → 웹앱(앱스토어 없이) 최소 기능 → 반응 보고 앱스토어
- 질문: 누가 살 만한 앱이 되려면 어떻게 해야 하나
- 답: 돈을 내는 건 '있으면 좋은 것'이 아니라 '결과'에 대해서. ① 누구 한 사람을 정하기 ② 경쟁 앱 낮은 별점 리뷰에서 불만 찾기 ③ 5~10명 인터뷰(미래 의향 말고 과거 행동을 묻기) ④ 가격을 적은 페이지로 사전 신청 받아보기
- 포지셔닝 후보: 직장인 업무일기 → 연말 성과평가·경력기술서 자동 정리 / 수험생·자격증 준비생 데일리 코치 / 다이어트·운동 습관 코치
- 확인: 이미 해본 것(노션 하루일기 템플릿, 매일 아침 피드백 세팅, 2025년 12월부터의 실제 사용 기록, 써보고 느낀 효과)이 그대로 상품 재료. 빠진 것은 '남들도 원하는지' 검증 하나
